## step1 (2026-10-19 ~ 2026-10-21)

**범위**: 구글 로그인, 로그인 없이 체험하기(익명 로그인 + 예시 기록, 3일 뒤 자동 삭제), 가계부·후기 작성·조회·수정·삭제(5초 되돌리기), 홈 캘린더, 기록 탭·타입 상세, 설정(타입 켜기/끄기, 다크모드, 로그아웃, 계정 삭제), 반응형(모바일·태블릿·PC), CI/CD, RLS 사용자 격리 테스트, E2E, 화면 비교

**병합한 PR**: 43개 (#1 ~ #46)

## step2 (2026-10-21 ~ 2026-10-22)

**범위**: 운동·체형·루틴 기록(루틴은 반복 규칙 + 하루 체크, 달성률), 기록 탭 "지난달보다" 비교, 검색(제목·메모·선택 칸)과 필드 정의로 만드는 필터, 오프라인(서비스 워커·홈 화면에 설치, 기록·루틴·설정의 기기 사본(IndexedDB)과 바뀐 것만 받는 동기화, 오프라인 작성 대기열(outbox), 한 번도 안 연 화면도 오프라인에서 열기, 로그아웃 때 기기 데이터 지우기), 오류 모니터링(Sentry, 개인 데이터 수집 끔), Lighthouse CI, 캘린더 성능 측정(한 달 300개)과 개선

**병합한 PR**: 24개 (#49 ~ #72)
