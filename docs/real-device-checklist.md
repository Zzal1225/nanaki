# 실기기(아이폰) 확인 체크리스트

자동 테스트가 볼 수 없는 것만 사람이 아이폰에서 확인한다. 약 10분.

## 언제 하나

- 화면 틀(레이아웃·하단 탭·시트), 입력칸, 서비스 워커, 로그인을 건드린 PR이 배포된 뒤
- step을 마칠 때 한 번 전체

그 밖의 PR은 하지 않는다. 같은 종류의 문제가 실기기에서 다시 나오면, 자동화할 수 있는지 먼저 보고 아래 "자동 테스트가 맡는 것"으로 옮긴다.

## 준비

- 사파리에서 배포 주소 → 공유 → **홈 화면에 추가**한 앱으로 확인한다. 상태 표시줄·홈 막대 동작은 홈 화면 앱에서만 다르다.
- 상태 표시줄 설정을 바꾼 PR이면 앱을 지우고 다시 추가한다. 아이폰은 추가할 때의 설정을 계속 쓴다는 보고가 있다.

## 1. 화면 가장자리 (홈 화면 앱)

- [ ] 맨 위에 있을 때와 아래로 스크롤했을 때 모두 글자가 상태 표시줄(시계·배터리)과 겹치지 않는다
- [ ] 하단 탭과 홈의 + 버튼이 홈 막대 위에 있다
- [ ] 작성 화면 맨 아래 저장 버튼이 홈 막대에 가리지 않는다
- [ ] 다크모드로 바꿔도 상태 표시줄 글자가 보인다

## 2. 키보드

- [ ] 검색어를 치는 동안 하단 탭·+ 버튼이 없고, 키보드를 내리면 다시 나온다
- [ ] 작성 화면의 맨 아래 입력칸(메모·태그)을 눌러도 키보드에 가리지 않는다
- [ ] 필터 시트의 숫자 칸을 눌러도 키보드에 가리지 않는다
- [ ] 나키 입력칸을 누르면 입력 줄(과 아래 안내 한 줄)이 키보드 바로 위에 붙고, 그 사이에 빈칸이 없다 (홈 화면 앱)
- [ ] 어떤 입력칸을 눌러도 화면이 확대되지 않는다
- [ ] 한글로 검색어를 치고 키보드의 "검색"을 한 번 누르면 한 번만 검색된다

## 3. 오프라인 (비행기 모드)

- [ ] 앱을 열고 10초쯤 둔 뒤 비행기 모드: 홈·기록 탭·검색·작성·한 번도 안 연 기록 상세가 열린다
- [ ] 새 버전이 배포된 다음 처음 열었을 때도 위와 같다
- [ ] 기록을 쓰면 "저장 대기"가 붙고, 비행기 모드를 끄면 사라진다
- [ ] 홈에서 루틴 체크가 된다
- [ ] 로그아웃을 누르면 "연결된 뒤 다시 시도" 안내만 뜨고 기록이 그대로다

## 4. 로그인·제스처

- [ ] 홈 화면 앱에서 로그아웃 → 구글 로그인 → 앱 안으로 로그인된 채 돌아온다
- [ ] 화면 왼쪽 가장자리를 밀어 뒤로 가기를 해도 화면이 멈추거나 튕기지 않는다
- [ ] 날짜 칸을 누르면 날짜 선택(바퀴)이 열리고 고른 날짜가 들어간다

## 5. 푸시 알림 (홈 화면 앱, 루틴 알림)

- [ ] Safari 탭에서 루틴 알림을 켜면 스위치 바로 아래에 "홈 화면에 추가한 앱에서만" 안내가 뜬다 — 2026-10-24 안 보임: 안내가 폼 끝에 있어 저장 줄에 가렸다 → #112에서 스위치 아래로 옮김, 다시 확인
- [ ] 홈 화면 앱에서 루틴 알림을 켜면 알림 허용 창이 뜨고, 허용하면 설정 > 알림에 "이 기기 루틴 알림"이 보인다
- [ ] 알림 시각이 지나면(10분 안) 잠금 화면에 루틴 알림이 오고, 누르면 그날 홈이 열린다
- [x] 그날 루틴을 이미 했으면 알림이 오지 않는다 — 2026-10-24 확인
- [x] 설정에서 끄면 다음 알림이 오지 않는다 — 2026-10-24 확인 (끄면 버튼이 사라져 다시 켤 수 없던 것은 #112에서 켜기·끄기 스위치로)
- [ ] (#112) 설정 > 알림 "이 기기 루틴 알림" 스위치를 껐다가 다시 켜면 알림이 다시 온다. Safari 탭에서는 스위치가 흐리고 "홈 화면 앱에서만" 안내

## 6. 사진 (눈바디)

- [ ] (38) 후기 쓰기 "사진 (선택 · 최대 5장)"의 ＋에서 보관함 사진을 여러 장 한 번에 고르면 칸이 늘고, 저장 뒤 상세 제목 아래에 가로 한 줄로 원래 비율 그대로 나온다
- [ ] (37d) 체형 화면의 "눈바디 비교"에서 사진 위를 손가락으로 좌우로 끌면 손잡이가 따라오고, 위아래로 밀면 화면이 스크롤된다. 날짜 칸을 누르면 사진이 있는 날짜 목록이 시트로 뜬다
- [x] 앱 안 카메라의 "갤러리에서 불러오기"로 아이폰 기본 카메라로 찍은 세로·가로 사진을 각각 골라 완료하면, 상세 썸네일이 바로 서 있다(돌아가지 않는다). — 2026-10-24 세로 사진 확인 (가로는 같은 경로라 생략) (#106부터 칸을 누르면 사진 찍기/보관함 선택 대신 앱 안 카메라가 열린다)
- [ ] HEIC 사진을 고르면 올리지 않고 "높은 호환성" 안내가 뜬다 (파일 앱에서 HEIC 고르기) — 2026-10-24 건너뜀: 아이폰 사진 보관함은 JPEG로 바꿔 줘서 실제로는 PC 끌어다 놓기에서 생기는 경우, 단위 테스트가 맡음
- [x] 썸네일을 누르면 크게 보이고, 바꾸기·지우기 버튼이 스크롤 없이 보인다 — 2026-10-24 확인 (아래 여백이 빠듯해 #110에서 홈 막대만큼 더함)
- [x] 비행기 모드에서 상세를 열면 "연결되면 사진을 볼 수 있어요" — 2026-10-24 확인 (쓰기 화면 안내는 #110에서 제목 옆 "사진은 오프라인 상태에서 저장할 수 없어요."로)
- [x] 사진을 고르면 "정면 사진 맞추기" 창이 뜨고, 사진을 손가락으로 끌면 화면이 같이 스크롤되지 않고 사진만 움직인다. 완료·다시 고르기 버튼이 홈 막대에 가리지 않는다 — 2026-10-24 확인
- [x] (37c2) 사진 칸을 누르면 앱 안 카메라가 뜬다: 처음 한 번 카메라 권한을 묻고, 후면 영상이 화면 폭 전체의 3:4 틀에 확대 없이(기본 카메라 4:3과 비슷한 화각) 보이며, 위 줄(닫기·타이머)·아래 셔터가 상태 표시줄·홈 막대에 가리지 않는다 — 2026-10-24 확인
- [x] (37c2) 거울 앞에서 후면으로 전신이 틀 안에 들어온다 — 2026-10-24 확인 (#107에서 확대 고친 뒤)
- [x] (37c2) 타이머 3초 → 셔터 → 3·2·1 뒤 찍히고, 세는 동안 셔터를 다시 누르면 취소된다 — 2026-10-24 확인
- [x] (37c2) 카메라를 닫으면 상태 표시줄의 카메라 사용 표시(초록 점)가 1~2초 안에 꺼진다. 설정에서 카메라를 거부해 두면 "카메라 권한이 꺼져 있어요" 안내와 갤러리 버튼만 — 2026-10-24 확인

## 자동 테스트가 맡는 것 (여기서 다시 보지 않는다)

| 확인                                                             | 테스트                                                        |
| ---------------------------------------------------------------- | ------------------------------------------------------------- |
| 입력칸 글자 16px 이상, 가로 넘침 없음, 터치 영역 44px            | `tests/e2e/iphone-pitfalls.mobile.spec.ts` (아이폰 크기·터치) |
| 검색 입력 중 하단 탭·+ 버튼 숨김                                 | 같은 파일                                                     |
| + → 쓰기 → 상세 → 수정 → 삭제·되돌리기, 닫았다 다시 연 작성 화면 | `tests/e2e/record-flow.mobile.spec.ts`                        |
| 오프라인 보기·작성·로그아웃 때 기기 데이터 지우기                | `tests/e2e/offline-flow.spec.ts`                              |
| 레이아웃 깨짐(로그인·홈·기록 탭·설정)                            | `tests/e2e/visual.spec.ts`                                    |

자동 테스트는 크로미움으로 아이폰 크기·터치를 흉내 낸다. 사파리 엔진(WebKit)으로도 돌리는 일은 다음 단계에서 한다.

## 기록
